# Pathfinder 

**Pathfinder** is an educational mobile robot designed as a learning by doing platform for exploring:

* Robotics
* Embedded programming
* Electronics
* Sensors and actuators
* Motor control
* 3D CAD
* FDM 3D printing
* Digital fabrication

The project is intended for **educational use and experimentation**.
> I've designed this robot for learning and experimentation and it a perfect educational project for learning by doing .

## Features

Pathfinder supports three operating modes:

* 🟢 **Automatic** — the robot detects obstacles, follows objects, and can detect drop-offs.
* 🔵 **Semi-automatic** — the operator controls the robot while the system helps maintain a minimum distance from obstacles.
* 🔴 **Manual** — full manual control without assistance.

The robot also includes:

* Ultrasonic obstacle detection
* Infrared drop-off detection
* Front and back signal LEDs
* WS2812B RGB status LED
* Buzzer
* Smartphone control via **Dabble app**
* 4-wheel drive
